# EMAIL-SMS-REMINDER-BOT

A simple Python project that allows users to set reminders and receive reminder alerts after a specific time.

## Features
- Set reminder messages
- Enter custom reminder time
- Displays reminder alert
- Beginner-friendly Python project
- Menu-driven program

## Technologies Used
- Python
- time module

## How It Works
1. User selects reminder option
2. User enters name and reminder message
3. User enters reminder time in seconds
4. Program waits for the given time
5. Reminder alert is displayed
